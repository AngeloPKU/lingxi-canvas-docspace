# 灵犀文档空间 Demo

本地打开 `index.html` 即可使用，无依赖安装或构建步骤。点击灵犀左侧的「文档空间」进入目录与文件列表。

## 交互

- 目录包含灵犀的云端产物、本地产物、文档分享、网页应用，以及 WPS 云文档的最近打开和我的文档。
- 目录支持展开与收起；点击文件夹进入下一级，通过面包屑返回上级。
- 文件列表支持类型筛选、修改时间排序、刷新和更多操作。
- 首页底部使用普通对话输入框。发送文字或所选文件后，在「最近」新建对话并自动进入该对话。
- 文件行悬停显示复选框，支持多选与当前列表全选。所选文件显示在输入框上方，移除卡片会同步取消勾选；切换目录保留已选文件，发送后清空。
- 新对话的用户消息包含所选文件卡片，点击卡片可在 Canvas 中预览。切换对话后附件仍然保留。
- 点击文件在应用内新增预览标签，支持文字、表格、演示文稿和示例网页应用。再次点击同一文件会激活已有标签。
- 文字、表格与演示文稿的预览标签使用对应的 WPS 彩色图标。
- 文档预览复用 Canvas 全屏视图，支持选区「灵犀帮改」、表格网格和幻灯片切页。
- 设置中的「文档空间全屏输入框」开关切换两种预览方案，切换即时生效并保存在当前浏览器。
- 开启输入框时，每次从预览发送会在「最近」新建对话，保持当前预览。用户请求、处理步骤和回复实时同步到该对话；回复气泡中的「打开完整对话」进入对应对话并定位该请求。
- 关闭输入框时，预览不显示底部输入框。标题栏「添加到对话」回到新任务页并带上当前文档。选区浮层的「添加到对话」带上文档、选区标签及指令；「发送」直接新建并进入对话，处理过程和回复在对话中展示。
- 从新任务页发送所带文档与选区后，文件和选区保留在消息中；选区修改完成后同步回原预览标签。
- 切换标签保留当前预览状态和输入内容；关闭正在处理请求的标签后，该请求仍继续，并将结果保留在左侧对话中。
- 「添加到任务」打开文件到当前对话的 Canvas，并在输入框添加文件引用文字。

## 演示数据

目录和文件内容使用内置示例。保存保留当前预览中的修改；刷新页面会重新载入示例数据。分享操作复制本 Demo 的预览链接，下载操作导出 HTML 预览。删除仅影响本次演示中的项目。

对话与选区处理沿用 Canvas 的演示逻辑，可在设置中配置 DeepSeek API Key。有全屏输入框的预览方案使用全屏回复气泡。
