# 灵犀文档空间 Demo

直接打开 index.html，点击左侧「文档空间」即可体验。无需安装依赖、运行本地服务。

## 文档预览与会话

- 支持 Word、Excel、PPT、图片及原有网页应用示例。图片示例为「团队协作流程图.svg」。
- 文档预览底部显示 mini 输入框。当前文档在发送时自动作为附件附带，发送前不显示当前文档卡片。
- 同一次打开文档，首次发送创建历史任务，后续提问复用该任务。切换 tab 或进入完整对话不会创建新任务；手动关闭后重开，首次发送才创建另一个任务。
- 文档空间 mini 与完整对话同步消息和文档内容。「打开完整对话」定位对应请求并保留来源文档 tab。
- 在 mini 气泡点击生成的文档卡片或网页链接，进入关联完整对话，并在右侧 Canvas 打开目标。输入「生成PPT」或「生成网页」可触发示例。
- 回复中的产物文件与网页链接只展示卡片，点击后才打开；普通对话与两种 mini 均使用这一规则。

## Canvas 与灵犀工作台

- 对话右上角的「展开右侧栏」可打开 Canvas。「收起侧栏」隐藏右侧 Canvas，保留该会话的文件标签、当前文件和修改；重新展开恢复。
- Canvas 第一个标签固定为「灵犀工作台」，不可关闭。点击后查看当前任务的执行进度，步骤「详情」可展开；未发送任务时显示等待状态。
- 关闭最后一个文件标签后，Canvas 留在工作台。文件标签右侧加号可从模拟文件选择器添加预览文件。
- 普通对话分屏及全屏 Canvas 提供工作台标签。工作台页展示任务进度；切回文件标签后恢复文件工具栏和对应 mini 输入框。文档空间沿用顶部的文件标签，文件预览内直接展示文档标题、工具栏和正文。

## 输入框与附件

- 文档空间 mini 默认显示，显隐状态只保留在当前打开的文件 tab 内。隐藏 A 文档不影响其他 tab；切回仍打开的 A 保持其当前状态。新打开文件、关闭后重开或刷新页面时，mini 默认显示。
- 普通对话 Canvas 全屏 mini 的显隐偏好保存在当前浏览器，重新进入或刷新后恢复。
- 隐藏状态下，选区「添加到对话」或「发送」会唤起当前 mini。普通对话同时更新显隐偏好；文档空间只更新当前文件 tab。
- 加号菜单支持「上传文件」和「执行环境」。模拟文件选择器预置 Word、Excel、PPT、图片；支持单选、Ctrl/Shift 多选、双击打开、目录切换、类型筛选和取消。
- 普通对话输入框未发送附件可在右侧预览；新任务及两种 mini 中未发送附件不可点击。发送后的用户消息附件可在完整对话中点击预览。
- 两种 mini 固定本地执行，其他输入框可在执行环境菜单切换本地、云端。切换仅表达演示运行环境。
- 设置中「文档空间使用 mini 输入框」开关保留两套方案。关闭后使用无输入框方案：标题栏添加到对话进入新任务；选区添加进入新任务并携带文档、选区与指令；选区发送新建并进入完整对话。

## 历史任务

- 所有会话均不显示文件夹图标。
- 按最近一次正式提交请求的时间排序。打开会话、输入草稿、空发送和收到回复不改变排序。

## 真实问答与演示剧情

在左下角「设置」保存阿里云百炼 API Key 后，新任务、普通对话、文档空间首页、文档空间 mini 和普通 Canvas 全屏 mini 的普通问答均使用 Qwen Flash 非思考模式。真实回复边生成边显示，并在关联的 mini 与完整对话之间同步。

- 问答携带最近 6 轮对话，以及附件的实际文本。Word 包含标题、段落和表格；Excel 包含当前工作表名称、单元格位置与数值；PPT 包含各页文字和备注。图片只传「[图片]」，不读取图像内容。
- 文档空间 mini 发送时自动附上当前文档；普通 Canvas 全屏 mini 只附带用户主动添加的附件。普通对话中当前打开的文档可作为问答上下文，内容按发送时最新状态读取。
- 同一附件在一次请求中只提供一份。附件数量或文本长度超出本地演示上限时，页面提示本次仅携带部分内容，模型上下文也会标注缺失。
- 普通问答可以解释文件、分析数据、提供修改建议或改写文本；通过选区「灵犀帮改」可实际写回文档。
- 明确要求生成文件或网页时使用内置模板，例如「生成PPT」「生成表格」「生成文档」「生成url」。产物与交互流程固定，不调用模型生成文件。
- 「总结这份报告」「解释这份PPT」「比较这些表格」属于普通问答。仅提到文件类型不会触发生成。
- 「仔细思考」用于演示长时间输出，保留固定长回复。预置历史消息和默认示例会话保留。
- 未配置 Key 或调用失败时使用演示回复；失败会轻提示，不阻断后续交互。选区帮改的固定完成文案保持「好的，已修改完成」。

文件与网页使用内置示例，模拟上传不读取用户电脑上的真实 Office 文件。文档修改在当前页面内保留并同步；刷新重新载入示例。Key 只保存在当前浏览器，不写入代码。

具体操作见 本地验收.md。
